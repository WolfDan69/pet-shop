# Pet Shop

Учебное fullstack-приложение: интернет-магазин товаров для животных
с возможностью добровольного благотворительного пожертвования.

При оформлении заказа покупатель может добавить сумму пожертвования
и выбрать благотворительную организацию на карте или из списка.

## Выбранный стек

- Frontend: React, TypeScript, Vite.
- Backend: Python, FastAPI.
- База данных: PostgreSQL, SQLAlchemy.
- Контроль версий: Git.

Библиотека UI-компонентов и инструменты карты будут выбраны
при реализации интерфейса.

## Основные пользовательские сценарии

1. Покупатель просматривает каталог и открывает карточку товара.
2. Добавляет товары в корзину и изменяет их количество.
3. Просматривает благотворительные организации на карте или в списке.
4. При оформлении заказа выбирает организацию и сумму пожертвования.
5. Проверяет итоговую сумму и оформляет заказ.
6. Получает подтверждение оформления.

Пожертвование необязательно и добавляется к стоимости товаров.
Первый вариант приложения использует демонстрационные данные
и не выполняет реальных платежей.

## Планируемые экраны первого этапа

- `/` — каталог товаров.
- `/products/:id` — карточка товара.
- `/cart` — корзина.
- `/charities` — благотворительные организации.
- `/checkout` — оформление заказа и выбор пожертвования.
- `/order-success` — подтверждение оформления.
- Страница «Не найдено» для неизвестных адресов.

## Границы первого этапа

Интерфейс на React и TypeScript, клиентская маршрутизация,
готовая библиотека UI-компонентов и базовая адаптивность.

Backend, регистрация пользователей и реальные платежи
в первый этап не входят.
